## 演示前检查清单

| # | 检查项 | 说明 |
|---|---|---|
| 1 | 视口 1920×1080、缩放 100% | 舞台是固定 1920×1080 坐标系，缩放会让章节里写的 px 不是屏幕上的 px |
| 2 | 字体本地化 | `public/fonts/` 有 114 个 woff2；CDN 不可达时页面**不白屏**，只退回系统字体，字重字距静默变样 |
| 3 | 打开**默认地址**（非 `?manual=1`） | 默认 = 有声成片态；调试态收在 `?manual=1`，深链 `?g=<step>` |
| 4 | 点一下画面或按空格放行音频 | 浏览器要求用户手势才允许播放；闸门消失后再开始录屏 |
| 5 | **确认声音出来了**再开始录屏 | 从闸门放行那一刻开始录，中途不操作 |

| 7 | `tokens.css` 在 `base.css` **之后** import | 同特异性下后来者胜，反了会静默吃掉主题性格层 |
| 8 | 真实截图已采齐 | `presentation/public/shots/` 下 S1–S4 四张，1920×1080 |

## 备用问答

> 第 9 章已经把最可能被问的那一条（文档数字漂移）讲进片子了。以下是现场仍可能被追问的。

**Q1：你们文档写 99 个提交，视频说 105，到底哪个对？**

答：两个都对，但说的是不同时刻。文档是**快照** —— 99 是助手上线那天的数字，之后又并了 6 个收口提交。视频统一用**实测口径**：对着 `v3.0` 和 `HEAD` 两个标签各量一次。这个差异是我们自己查出来的，已经写进片子和备用问答。

**Q2：为什么上屏的表数是 26，而路线图文档里写的是 20 张表？**

答：同上一条，是快照。实测 `backend/sql/V*.sql` 里的 `CREATE TABLE`：`v3.0` 时 22 张（V1 建 21 + V4 加 1），`HEAD` 时 26 张（V5 加 2 + V6 加 1 + V7 加 1）。

**Q3：距离排序到底能不能用？**

答：**要坐标才算得出来**。代码路径是通的（V7 迁移把坐标和可服务时段变成可索引的结构化列），陪诊员档案里补上坐标之后，这一维第一次真的参与排序 —— 候选卡上的「距离约 2 公里」就是实算值。满量程 30 公里，权重 20%。

**Q4：AI 助手的知识库 179 条，靠谱吗？**

答：**现在只是覆盖度，不是准确度**。179 条是从业务文档和历史问题生成的**模拟问法**，用来把关键词检索的召回面铺开；它没有经过真实用户提问验证，所以报告里这条的状态是「保持未关闭」，关闭条件是上线后真实回流。这是我们主动写进片子的，不是包装。

**Q5：安全上还有什么没解决的？**

答：P0/P1 已经在 `37279b6` / `c25e571` 两个提交里修了（生产配置 fail-closed、证件上传鉴权收窄）。剩下两条属**纵深防御缺口**，不是已知可利用漏洞：F-08 是 SSE/WebSocket 的令牌走 URL query（会进访问日志和 Referer），F-10 是 token 存在 localStorage。两条都已记录在 `docs/security/安全评估报告-2026-10-18.md`，我们选择按风险接受并排进下一阶段。

**Q6：为什么不做在线支付和地图导航？**

答：两条都是红线。支付涉及资质与资金合规；地图导航在项目一期是文字地址加签到坐标，导航需要持续的位置精度授权，而且「距离」这个维度在坐标数据到位之前也没有业务含义。它们不是没时间做，是**做早了没有意义**。

**Q7：聊天为什么不做成可以随便加好友？**

答：`docs/adr/0011-order-chat.md:77-81` 记了取舍：陪诊员可以主动触达家属就是骚扰面。所以聊天**严格按订单建会话**，家属和接单陪诊员在这个订单范围内沟通，不做跨单聚合、不做主动触达。聊天沿用全部合规约束（敏感词拦截、脱敏、免责声明）。

**Q8：这些功能到底有多少是评审要求你们做的，多少是你们自己判断的？**

答：三类来源都真实存在。最典型的是履约保障 —— `docs/spec/V3.x-roadmap-spec.md:18` 明确写着这是「当前最容易被评审追问的单点」，我们把它排进 V3.1。老人健康协同来自家属侧真实诉求（「我爸妈这个月怎么样」要跨四页人工拼）。智能助手则是合规与体验共同推出来的。**没有一个版本是为了「显得功能多」而做的** —— roadmap 的价值门禁里第一条就是「是否解决真实用户问题」。

**Q9：新增这么多功能，技术债还剩多少？**

答：我们做了三件对冲的事：迁移全走 expand-contract 契约式（先加可空列、老数据不受影响、旧列保留、一期不删）；流水线把后端、前端、密钥体检、助手服务、指标字典一致性全卡住；越权矩阵用真实 HTTP 请求跑端点×角色矩阵，100 次 0 违规。**但要说实话**：定时任务那一层覆盖率只有 4.35%，服务层 63.26%、门禁线 60%、余量只剩 3.26 个百分点，这是下一阶段要补的。

**Q10：视频里的数字能不能当场验？**

答：能。第 9 章那张表里每一条都标了复核命令，仓库里直接跑就能复现。比如端点数：`git grep -h -E '^\s*@(Get|Post|Put|Delete|Patch)Mapping' v3.0 -- 'backend/src/main/java/**/*.java'` 与 `HEAD` 各跑一次，数量分别是 82 和 114。
