# 医疗建议类表述的合规词表 —— 单一真源
#
# ⚠️ 本文件是「不做诊断、不开药方」红线在代码层的唯一落点。
#
# 谁在读它：
#   · Java  —— util/ComplianceCheckUtil.java（classpath 读取，行为不变）
#   · Python —— ai-service/app/paths.py（NIANGLIN_COMPLIANCE_WORDS_PATH 可配）
#
# 为什么必须共用一份：
#   ComplianceCheckUtil 的 javadoc 写过一句话 ——
#   「不要另起一份词表 —— 两份词表一定会有一份先过期。」
#   本文件是该纪律的落地形式：Python 侧不再抄一份，
#   而是读同一份。失效方式从「静默分叉」变成「读不到就启动失败」。
#
# 词表刻意「宁可误拒」：
#   被拒时用户能看到具体命中的词，改写成本很低；
#   而漏放一条「建议加量」的代价无法挽回。
#   刻意**不含**「药」「医院」「治疗」这类宽泛词 ——
#   「已协助取药」是完全合法的过程记录。
#
# 格式：一行一个词；空行与 # 开头的行被忽略；改词表要同时更新两侧的快照断言。
