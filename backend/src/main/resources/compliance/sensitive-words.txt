# 辱骂 / 违规引流词表 —— 单一真源

# ⚠️ 本文件是「辱骂 / 平台外交易 / 私下联系」三类表述的唯一落点。
#
# 谁在读它：
#   · Java  —— util/SensitiveWordUtil.java（classpath 读取，行为不变）
#   · Python —— ai-service/app/paths.py（NIANGLIN_SENSITIVE_WORDS_PATH 可配）
#
# 为什么与「医疗建议词表」分开成两个文件：
#   两张表拦的是**完全不同**的东西。
#   · medical-advice-words.txt —— 诊断 / 处方 / 用药建议类表述（医疗红线）
#   · sensitive-words.txt      —— 辱骂 / 违规引流（内容合规）
#   合并会让人以为「只要不是骂人就可以随便说医疗建议」—— 那是两回事。
#
# 词表刻意保持**短小**：长词表会带来大量误伤（例如「滚」会命中「滚烫」），
# 而一期并没有内容审核的人工兜底能力。
# 这里只覆盖最明确、几乎不存在正常用法的几个词。
#
# 格式：一行一个词；空行与 # 开头的行被忽略。
